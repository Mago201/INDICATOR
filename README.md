# SmartMoneyVolume — индикатор для MetaTrader 5

**v1.20** — добавлены **Entry signals** (стрелки точки входа по совпадению условий) + исправление производительности.
**v1.30** — расширенный **Entry engine**: Premium/Discount фильтр, Strong (displacement) Order Blocks, авто SL/TP с фильтром по R:R, Score-режим вместо all-or-nothing, cooldown / anti-clustering, rejection-фитиль, VP confluence.
**v1.31** — модуль **Liquidity Levels**: линии ликвидности BSL/SSL от свингов с авто-снятием при пробое, **Equal Highs/Lows (EQH/EQL)**, дневные (PDH/PDL/CDH/CDL) и сессионные (Asia/London/NY) уровни + счётчики в Dashboard.
**v1.40** — **Alert при снятии ликвидности** (BSL/SSL, с push-опцией), новый Entry-фильтр **«liquidity grab → CHoCH»** (вход после снятия ликвидности с последующей сменой характера) + его вес в score-режиме, и **подсветка непротестированных уровней** (свежие OB / линии ликвидности отдельным цветом).

Один индикатор объединяет:
- **Smart Money Concepts (SMC)** — структура, BOS, CHoCH, OB, FVG, sweeps
- **Анализ объёмов** — подсветка громких свечей
- **Multi-Timeframe** — структуру старшего ТФ прямо на текущем графике
- **Order Block mitigation** — отметку сработавших и активных зон
- **Dashboard** — счётчик всех сигналов в углу графика
- **Volume Profile** — POC / VAH / VAL с любого таймфрейма
- **Entry signals** — стрелки точки входа когда совпадают несколько подтверждений

## Что показывает

| Элемент | Описание |
|---|---|
| **HH / HL / LH / LL** | Метки структурных свингов |
| **BOS** (сплошная) | Пробой структуры в направлении тренда |
| **CHoCH** (пунктир) | Смена характера рынка / разворот |
| **Order Blocks** | Зоны последнего противоположного бара перед импульсом. **Серые с пунктиром** = mitigated |
| **Fair Value Gaps** | 3-свечные имбалансы |
| **Liquidity Sweeps** | Стрелки в местах снятия ликвидности |
| **Liquidity Levels** | Линии BSL/SSL от свингов (снятые — серым), EQH/EQL, дневные PDH/PDL/CDH/CDL и сессионные H/L |
| **Непротестированные уровни** | Свежие OB / линии ликвидности, к которым цена ещё не возвращалась — отдельным цветом (v1.40) |
| **High-Volume bars** | Стрелки над/под объёмными свечами |
| **MTF структура** | Свинги/BOS/CHoCH/OB старшего ТФ (синим/малиновым) |
| **Volume Profile** | Гистограмма объёмов по ценовым уровням + POC/VAH/VAL |
| **Entry signals** | Большие зелёные/красные стрелки — точка входа при совпадении выбранных условий |
| **Dashboard** | Панель в углу со счётчиками всех сигналов |

## Установка

1. MT5 → **Файл → Открыть каталог данных** → `MQL5/Indicators/`.
2. Скопируйте [`Indicators/SmartMoneyVolume.mq5`](Indicators/SmartMoneyVolume.mq5) в эту папку.
3. В MetaEditor (`F4`) откройте файл и нажмите **Compile** (`F7`).
4. В «Навигаторе» MT5 обновите список и перетащите индикатор на график.

## Параметры

### Структура (Swing / BOS / CHoCH)
- `InpSwingLength` — баров слева/справа для подтверждения свинга. Больше = крупнее структура.
- `InpShowSwings`, `InpShowBOS`, `InpShowCHOCH` — переключатели элементов.
- `InpBullColor` / `InpBearColor` — цвета.

### Order Blocks + Mitigation
- `InpShowOB` — включить ордер-блоки.
- `InpOBMaxCount` — максимум активных OB на сторону.
- `InpOBExtendBars` — длина прямоугольника вправо.
- `InpOBHideMitigated` — `true` = удалять сработавшие OB; `false` = показывать серым.
- `InpOBMitigatedClr` — цвет сработавшего OB.
- `InpOBExtendOnTouch` — обрезать прямоугольник на момент касания (правая граница = бар касания).

### Fair Value Gaps
- `InpShowFVG`, `InpFVGMaxCount`, `InpFVGExtendBars`, `InpBullFVGColor`, `InpBearFVGColor`.

### Liquidity Sweeps
- `InpShowLiquidity`, `InpLiquidityColor`.

### Liquidity Levels (зоны ликвидности)
Показывает **где лежит ликвидность** (резерв стопов) и снимает её визуально, когда цена проходит уровень.

- `InpLiqLevelsEnable` — включить весь модуль.
- `InpLiqShowLines` — рисовать линии ликвидности от свингов: **BSL** (buy-side) над максимумами, **SSL** (sell-side) под минимумами.
- `InpLiqBuyColor` / `InpLiqSellColor` — цвета активных BSL / SSL.
- `InpLiqLineStyle` / `InpLiqLineWidth` — стиль и толщина линий.
- `InpLiqMaxPerSide` — максимум активных линий на сторону (старые удаляются).
- `InpLiqRemoveOnSweep` — `true` = удалять линию при снятии; `false` = затемнять (`InpLiqSweptColor`) и обрывать на баре снятия.
- `InpLiqSweptColor` — цвет снятой ликвидности.
- `InpLiqShowLabels` — подписи у линий (BSL/SSL/EQH/EQL/PDH…).
- `InpLiqExtendActive` — тянуть активные линии лучом вправо.
- `InpLiqAlert` — **алерт в момент снятия ликвидности** (когда цена проходит линию BSL/SSL). Срабатывает только на свежем баре — без спама на истории.
- `InpLiqAlertPush` — дополнительно отправлять push-уведомление на телефон (`SendNotification`; требует настроенного MetaQuotes ID в MT5).

**Equal Highs / Lows (EQH/EQL)** — два почти равных экстремума = «двойная вершина/дно», сильный магнит ликвидности.
- `InpLiqShowEqual` — включить EQH/EQL.
- `InpLiqEqualColor` — цвет соединительной линии.
- `InpLiqEqualTolATR` — допуск «равенства» в долях ATR (0.10 = 10% ATR; если ATR недоступен — запасной допуск в пунктах).

**Дневные уровни** — институциональные ориентиры.
- `InpLiqShowDaily` — рисовать PDH/PDL (вчера) и CDH/CDL (сегодня).
- `InpLiqDailyColor` — цвет дневных уровней.

**Сессионные H/L** — ликвидность сессий по серверному времени.
- `InpLiqShowSessions` — включить.
- `InpLiqAsiaColor` / `InpLiqLondonColor` / `InpLiqNYColor` — цвета сессий.
- `InpLiqAsiaStart` / `InpLiqAsiaEnd`, `InpLiqLondonStart` / `InpLiqLondonEnd`, `InpLiqNYStart` / `InpLiqNYEnd` — окна сессий (час сервера). Настройте под брокера.

> Линия снимается, когда цена **проходит уровень** (`high > BSL` или `low < SSL`). Проверка инкрементальная — как у OB mitigation, без перерисовки. В Dashboard добавлена секция **Ликвидность**: активные BSL/SSL, снято линий, кластеры EQH/EQL.

### Подсветка непротестированных уровней (v1.40)
Выделяет **свежие зоны/уровни, к которым цена ещё не возвращалась**, отдельным цветом — чтобы непротестированные сетапы сразу бросались в глаза. Уровень считается «протестированным» при первом возврате цены: для OB — когда зона сработала (mitigation), для линии ликвидности — когда она снята (sweep).

- `InpHighlightUntested` — включить подсветку.
- `InpUntestedColor` — цвет свежих (непротестированных) зон и уровней.
- `InpUntestedApplyOB` — применять к Order Blocks (свежий = ещё не сработавший OB рисуется этим цветом; после mitigation — обычным «серым»).
- `InpUntestedApplyLiq` — применять к линиям ликвидности (свежая BSL/SSL рисуется этим цветом; после снятия — `InpLiqSweptColor`).

> Подсветка не затрагивает MTF Order Blocks (они трекаются на своём ТФ). Цвет применяется в момент создания зоны и сохраняется до её первого теста.

### Объёмы
- `InpShowVolume` — подсвечивать объёмные свечи.
- `InpVolumeType` — `VOLUME_TICK` или `VOLUME_REAL` (для бирж с реальными объёмами).
- `InpVolumePeriod` — период скользящей среднего объёма.
- `InpVolumeMultiplier` — во сколько раз выше среднего, чтобы считать «громким». 1.8 = +80%.
- `InpShowVolText`, `InpVolTextColor` — текстовая подпись объёма.

### MTF (старший таймфрейм)
- `InpMTFEnable` — отображать структуру старшего ТФ на текущем графике.
- `InpMTFPeriod` — какой ТФ анализировать (например, H1 на M15-чарте).
- `InpMTFLookback` — сколько баров MTF брать для анализа (по умолчанию 300).
- `InpMTFShowSwings`, `InpMTFShowBOS`, `InpMTFShowCHOCH`, `InpMTFShowOB` — что рисовать.
- `InpMTFBullColor` / `InpMTFBearColor` — цвета MTF структур (по умолчанию голубой/малиновый, чтобы отличать от обычных).
- `InpMTFBullOBClr` / `InpMTFBearOBClr` — цвета MTF OB.
- `InpMTFLineWidth` — толщина MTF-линий (рекомендую 2 для контраста).

> Если выбрать ТФ младше текущего, MTF-блок будет проигнорирован (защита).

### Dashboard
- `InpDashEnable` — показывать панель.
- `InpDashCorner` — угол графика (`CORNER_RIGHT_UPPER` по умолчанию).
- `InpDashX` / `InpDashY` — отступ от угла в пикселях.
- `InpDashWidth` — ширина панели.
- `InpDashTextColor`, `InpDashBgColor`, `InpDashAccent` — цвета.
- `InpDashFont`, `InpDashFontSize` — шрифт (рекомендую моноширинный).

Панель показывает:
- Текущий тренд по структуре (BULL/BEAR/FLAT) на текущем и MTF-таймфреймах
- Счётчики BOS+/-, CHoCH+/-, Sweeps+/-, HH/HL/LH/LL
- OB активные/сработавшие отдельно для бычьих и медвежьих
- FVG +/-
- Громкие свечи +/- с указанием множителя
- Ликвидность: активные BSL/SSL, снято линий, кластеры EQH/EQL
- Параметры активного Volume Profile

### Volume Profile
- `InpVPEnable` — включить.
- `InpVPTimeframe` — на каком ТФ считать профиль (`PERIOD_CURRENT` = текущий). Можно построить D1-профиль на M15-графике.
- `InpVPLookback` — сколько баров `InpVPTimeframe` использовать.
- `InpVPRows` — на сколько ценовых зон делить диапазон.
- `InpVPWidthPct` — какую часть видимой области графика занимает гистограмма (в %).
- `InpVPColor` — цвет обычных строк.
- `InpVPPocColor` — цвет POC (Point of Control — самая объёмная зона).
- `InpVPVaColor` — цвет Value Area (зоны с ~70% объёма вокруг POC).
- `InpVPShowPoc` / `InpVPShowVa` — рисовать ли горизонтальные линии POC/VAH/VAL.
- `InpVPValueArea` — доля объёма для VA (по умолчанию 0.70 = 70%).
- `InpVPRightSide` — `true` = гистограмма растёт ВЛЕВО от правого края (стандарт), `false` = вправо.

### Entry signals (стрелки точки входа)
Большие зелёные/красные стрелки появляются на тех барах, где **одновременно совпали** все включённые условия. Каждое условие — отдельный чекбокс:

- `InpEntryEnable` — глобальное включение.
- `InpEntryNeedTrend` — текущий тренд по структуре должен совпадать с направлением сигнала (для BUY — BULL, для SELL — BEAR).
- `InpEntryNeedMTF` — то же для тренда MTF (старшего ТФ). Имеет смысл при `InpMTFEnable=true`.
- `InpEntryNeedOB` — цена бара (диапазон [low, high]) должна пересекаться с **активным (не сработавшим) OB** соответствующего цвета.
- `InpEntryNeedVolume` — текущий бар должен быть **громким** того же цвета (зелёный для BUY, красный для SELL).
- `InpEntryNeedSweep` — недавно произошёл sweep ликвидности в обратную сторону (для BUY — sweep лоёв, для SELL — sweep хаёв).
- `InpEntryNeedStruct` — недавно произошёл BOS/CHoCH в нужную сторону.
- `InpEntryRecencyBars` — окно «недавности» в барах (5 по умолчанию). Используется для sweep и struct условий.
- `InpEntryUpColor` / `InpEntryDnColor` — цвета стрелок.
- `InpEntryUpArrow` / `InpEntryDnArrow` — Wingdings-коды (233 = ▲, 234 = ▼, 217/218 — большие стрелки, 5/6 — точки).
- `InpEntryArrowWidth` — толщина (по умолчанию 4).
- `InpEntryArrowShift` — смещение от свечи в пикселях.
- `InpEntryAlert` — алерт при появлении entry-сигнала.

**Рекомендуемые конфигурации:**

| Стиль | NeedTrend | NeedMTF | NeedOB | NeedVol | NeedSweep | NeedStruct |
|---|---|---|---|---|---|---|
| Лояльный (много стрелок) | ✓ | — | — | ✓ | — | — |
| Сбалансированный (default) | ✓ | — | ✓ | ✓ | — | — |
| Строгий по тренду | ✓ | ✓ | ✓ | ✓ | — | ✓ |
| Контртрендовый разворот | — | — | ✓ | ✓ | ✓ | ✓ |

> **Примечание:** для бычьего входа условие «sweep в обратную сторону» означает sweep лоёв (взяли стопы продавцов снизу). Для медвежьего — sweep хаёв.

### Расширенные Entry-фильтры (v1.30)

Дополнительные фильтры качества — каждый можно включить независимо. Если ни один не активирован, индикатор работает по старой схеме «AND всех чекбоксов».

#### Premium / Discount
Классика SMC: BUY имеет смысл в нижней половине последнего диапазона `[lastL .. lastH]` (discount), SELL — в верхней (premium). Отсекает значительную часть «плохих» точек.
- `InpEntryNeedPremDisc` — включить фильтр.
- `InpEntryPremDiscMTF` — брать диапазон с MTF-структуры вместо текущего ТФ.
- `InpEntryPremDiscMid` — граница (0.5 = ровно середина).
- `InpEntryPremDiscDelta` — буфер от середины (0.05 = 5% от диапазона).

#### Strong / Displacement Order Blocks
OB помечается как «сильный» если сразу после него был импульс с FVG (institutional displacement). Такие OB рисуются **толще** (`WIDTH=2`).
- `InpEntryNeedStrongOB` — давать сигнал только из «сильных» OB.
- `InpEntryOBImpulseMaxBars` — макс. баров после OB для поиска FVG-импульса (по умолчанию 6).

#### Auto SL/TP + R:R фильтр
Автоматический расчёт стопа и целей; стрелка появляется только если соотношение риск/прибыль ≥ порога.
- `InpEntryNeedRR` — жёсткий фильтр по RR.
- `InpEntryMinRR` — минимальное R:R (рекомендую 1.5–2.0).
- `InpEntrySLATRMult` — буфер SL за границу OB в долях ATR (0.30 = ATR×0.3).
- `InpEntryATRPeriod` — период ATR (14 по умолчанию).
- `InpEntryUseVPForTP` — учитывать POC/VAH/VAL как кандидатов для TP.
- `InpEntryShowLevels` — рисовать пунктиры SL (красный, dash) / TP1 / TP2 (зелёный, dot) у стрелки.
- `InpEntryShowLabel` — текст «s7 RR2.30» рядом со стрелкой.
- `InpEntryLevelsBars` — длина пунктиров вправо (баров).

Кандидаты TP: ближайший противоположный OB → POC/VAH/VAL → последний свинг. Сортируются по расстоянию от текущей цены.

#### Rejection wick
Бар сигнала должен иметь явную реакцию — нижний фитиль > body для BUY (или верхний для SELL).
- `InpEntryNeedReject` — требовать rejection.

#### Liquidity grab → CHoCH (v1.40)
Полноценный SMC-сценарий входа: сначала **снятие ликвидности** (sweep свинга в обратную сторону), затем **CHoCH** в направлении сделки — это подтверждает, что ликвидность собрана и рынок развернулся.
- BUY: снятие sell-side ликвидности (sweep лоёв) → бычий CHoCH.
- SELL: снятие buy-side ликвидности (sweep хаёв) → медвежий CHoCH.

Параметры:
- `InpEntryNeedGrabChoCH` — требовать паттерн (жёсткий гейт; работает и в AND-, и в score-режиме).
- `InpEntryGrabMaxBars` — максимум баров между снятием ликвидности и CHoCH (по умолчанию 8). После CHoCH сигнал актуален в пределах `InpEntryRecencyBars`.
- `InpEntryWeightGrabChoCH` — вес паттерна в score-режиме (по умолчанию 3).

#### Cooldown / anti-clustering
Не давать «гирлянды» стрелок на одном движении.
- `InpEntryCooldownBars` — N баров «тишины» после стрелки того же направления.
- `InpEntryMinDistATR` — минимальная дистанция от прошлой стрелки в ATR (0.5–1.0 типично).

### Score-режим (вместо «всё или ничего»)
Каждое условие даёт N очков; стрелка появляется когда `score ≥ MinScore`. Удобно когда хочется «3-из-4 совпало = достаточно».

- `InpEntryUseScore` — включить score-режим.
- `InpEntryMinScore` — порог (по умолчанию 6).
- `InpEntryWeight*` — веса каждого условия (Trend, MTF, OB, StrongOB, Volume, Sweep, Struct, PremDisc, RR, VPCnflu, Reject, GrabChoCH).

> Если включён `Use Score` + любой `Need*` — этот `Need*` становится **жёстким гейтом** (не очко, а обязательное условие). Удобно: «считаем score, но без OB вообще не входим».

В дашборде показывается режим (`Mode: score >= 6` или `AND-gates`) и активные фильтры.

**Рекомендуемые пресеты v1.30:**

| Пресет | Score? | Min | Need-гейты | Min RR | PremDisc | StrongOB | Cooldown |
|---|---|---|---|---|---|---|---|
| **Качество (мало, точно)** | ✓ | 8 | Trend, OB, StrongOB | 2.0 | ✓ | ✓ | 5 |
| **Сбалансированный** | ✓ | 6 | Trend, OB | 1.5 | ✓ | — | 3 |
| **Лояльный (много, для скрининга)** | ✓ | 4 | OB | 1.0 | — | — | 0 |
| **Контртренд по sweep+CHoCH** | ✓ | 6 | OB, Sweep, Struct | 1.5 | ✓ | — | 5 |

### Прочее
- `InpObjPrefix` — префикс имён объектов (изолирует индикатор от других).
- `InpAlertOnBOS`, `InpAlertOnSweep` — звуковые алерты для свежих сигналов.

## Стратегии применения

### 1. Тренд по MTF + вход по локальному OB
Если `InpMTFPeriod = H1` показывает BULL и есть свежий H1-BOS, ищите на M15:
- Bullish OB на M15 в зоне H1-OB
- Подтверждение громким объёмом (стрелка)
- Вход на касании M15-OB, стоп под ним

### 2. Контртренд по CHoCH + sweep ликвидности
- Sweep противоположной зоны (стрелка золотая)
- Сразу после — CHoCH = ранний сигнал разворота
- Усиление: касание VAH/VAL Volume Profile

### 3. Magnet trade — FVG/POC
- FVG не закрыт → цена с высокой вероятностью вернётся его заполнить
- POC = магнит для цены (наибольший объём)
- Используйте как цель TP

### 4. Dashboard scan
- За сессию смотрим: тренд на двух ТФ совпадает? Сколько было BOS / CHoCH? Высокий ли объём?
- Если несколько индикаторов согласуются — высоко-качественный сетап

## Особенности

- **Без перерисовки структур.** Свинги подтверждаются только когда после них прошло `InpSwingLength` баров.
- **Объёмная стрелка может «мерцать»** на текущем баре, пока он не закрыт — это нормально.
- **OB mitigation** срабатывает на первом касании зоны (low внутри bull-OB или high внутри bear-OB) и считается необратимым.
- **MTF пересчитывается** только при появлении нового бара старшего ТФ — производительно даже на длинной истории.
- **Volume Profile** перестраивается с каждым новым баром текущего ТФ.

| Сценарий | InpSwingLength | InpMTFPeriod | InpVolumeMultiplier |
|---|---|---|---|
| Скальпинг M1/M5 | 8–12 | M30 / H1 | 2.0–2.5 |
| Дейтрейдинг M15/M30 | 5–7 | H1 / H4 | 1.7–2.0 |
| Свинг H1/H4 | 3–5 | D1 / W1 | 1.5–1.8 |
| Биржевые рынки (фьючи, акции, MOEX) | — | — | `InpVolumeType = VOLUME_REAL` |

# GoldScalperPro — скальпинг/интрадей для золота (XAUUSD) v1.00

Отдельный самостоятельный индикатор, заточенный под **высокий винрейт внутри дня**. Логика — трендовый вход на откате (pullback continuation), а не угадывание разворотов: торгуем **по тренду**, входим **на откате**, с жёсткими фильтрами и встроенной оценкой винрейта по истории.

## Логика сигнала (конфлюенс)

Сигнал **BUY** появляется на закрытии бара, когда совпало всё:
1. **Тренд вверх** — стек EMA: `EMA8 > EMA21 > EMA50`.
2. **Bias по VWAP** — цена выше дневного VWAP (институциональная справедливая цена).
3. **Откат** — в окне последних N баров цена коснулась быстрой EMA, а RSI проваливался `<= RsiBuyDip` (откат состоялся).
4. **Импульс-триггер** — RSI развернулся вверх и `>= 50` (но не в перекупленности), бар бычий и закрылся выше быстрой EMA.

**SELL** — зеркально (тренд вниз, цена ниже VWAP, всплеск RSI на откате вверх, медвежий разворот).

> Почему высокий винрейт: вход строго по тренду + на откате (хорошая цена) + R:R = 1.0 по умолчанию (механически выше процент попаданий). Винрейт ≠ прибыльность — поэтому на панели сразу видны **profit factor** и **expectancy в R**, чтобы балансировать.

## Фильтры

- **Сессия** (`InpUseSession`, часы сервера) — по умолчанию 8–21 (London+NY), отсекает «пилу» азиатской сессии и роллловер.
- **Волатильность** (`InpAtrMinPts` / `InpAtrMaxPts`) — не торговать в штиль и в экстремальную волу.
- **Спред** (`InpMaxSpreadPts`) — для live: пропускать сигналы при широком спреде (золото бывает «дорогим»).
- **Cooldown / min distance** — без «гирлянд» сигналов на одном движении.

## Риск (SL/TP)

- `InpSLATR` — стоп в долях ATR (по умолчанию 1.2×ATR), `InpSLUseSwing` — за локальный экстремум.
- `InpRR` — соотношение риск/прибыль (по умолчанию **1.0** под высокий винрейт; поднимите до 1.5–2.0 для большего профита ценой винрейта).
- SL/TP последних сигналов рисуются на графике (`InpShowLevels`).

## Dashboard со статистикой винрейта

Панель в углу графика считает по видимой истории (forward-test каждого сигнала: что наступило первым — TP или SL):
- **Win-rate %**, **Win/Loss/open**, всего сигналов (Buy/Sell).
- **Profit factor** и **Expectancy (R)**.
- Текущий bias (тренд+VWAP), статус сессии, ATR (пункты), спред.

Это превращает подбор параметров в измеримый процесс: меняете настройки → сразу видите винрейт и матожидание. Forward-test — консервативный (если в одном баре задеты и SL, и TP — засчитывается как убыток).

## Установка и применение

1. Скопируйте [`Indicators/GoldScalperPro.mq5`](Indicators/GoldScalperPro.mq5) в `MQL5/Indicators/`, скомпилируйте (`F7`).
2. Откройте **XAUUSD**, ТФ **M1–M15** (скальпинг — M1/M5, интрадей — M15).
3. Подстройте `InpSessStartHour/EndHour` под время сервера брокера (важно!).
4. Прогоните по истории, смотрите Win-rate/Expectancy на панели, тюньте `RsiBuyDip/SellPop`, `SLATR`, `RR`, фильтры ATR.

| Параметр под винрейт | Эффект |
|---|---|
| `InpRR = 1.0` | максимум попаданий (TP близко) |
| `InpRR = 1.5–2.0` | меньше винрейт, больше прибыль на сделку |
| строже `InpRsiBuyDip` (ниже) / `InpRsiSellPop` (выше) | реже сигналы, глубже откат |
| уже окно сессии | только лучшие часы |

> ⚠️ Винрейт по истории — это оценка на барных данных (без учёта проскальзывания/комиссии/спреда внутри бара). Используйте как инструмент сравнения настроек, а не гарантию. Перед реальной торговлей проверяйте в тестере стратегий.

# SmartMoneyVolumeEA — автоматический советник (Expert Advisor) v1.00

Советник автоматизирует **entry-сигналы** индикатора `SmartMoneyVolume`. Поскольку индикатор большой и хранит состояние (свинги, BOS/CHoCH, OB + mitigation, sweeps, premium/discount, Volume Profile), советник построен по архитектуре **«мост»**: он загружает индикатор через `iCustom`, читает его буферы стрелок входа (EntryUp/EntryDn) и **исполняет** сделки с риск-менеджментом. Логика сигнала при этом не дублируется — её источник один: сам индикатор.

> Это значит: что нарисовал индикатор (зелёная/красная стрелка входа), то и торгует советник. Все фильтры индикатора (score-режим, Premium/Discount, Strong OB, RR, grab→CHoCH, MTF и т.д.) работают внутри индикатора «как есть».

## Как это работает

1. EA через `iCustom("SmartMoneyVolume")` запускает индикатор с его **значениями по умолчанию** (см. ниже про лимит параметров).
2. Каждый тик EA сканирует последние `InpSignalScanBars` баров и берёт **самый свежий** сигнал в буферах **EntryUp** (покупка) / **EntryDn** (продажа).
3. При появлении новой стрелки EA открывает сделку **по рынку**, рассчитывает SL/TP по ATR, объём по риску и далее сопровождает позицию.

### ⚠️ Важно: лимит параметров iCustom и настройка стратегии
В MQL5 действует жёсткое ограничение — **не более 63 аргументов** у `iCustom`. У индикатора `SmartMoneyVolume` ~149 входов, и entry-параметры расположены **в конце** списка, поэтому передать их через `iCustom` невозможно (префиксом до них не добраться). Из-за этого советник запускает индикатор с его **значениями по умолчанию** (дефолт = пресет «Сбалансированный»: тренд + активный OB + объём, AND-режим).

**Как сменить пресет/настройки входа:** отредактируйте значения по умолчанию во входах самого `Indicators/SmartMoneyVolume.mq5` (например, включите `InpEntryUseScore`, `InpEntryNeedPremDisc`, поднимите `InpEntryMinRR`, и т.п.) и **перекомпилируйте индикатор** — советник через `iCustom` подхватит новые дефолты. Параметры риска/исполнения настраиваются прямо во входах советника.

> Дефолты индикатора уже включают всё, что нужно entry-движку (`InpShowOB`, `InpShowBOS`, `InpShowCHOCH`, `InpShowLiquidity`, `InpShowVolume` = true), — детект в индикаторе завязан на эти флаги. Не выключайте их, иначе соответствующие условия входа перестанут работать.

### Важно: задержка подтверждения
Индикатор подтверждает стрелку входа только после подтверждения свинга — то есть спустя **`InpSwingLength` баров** (`last_confirmable = rates_total − InpSwingLength − 1`, по умолчанию 5). EA входит **в текущей рыночной цене** в момент появления подтверждённой стрелки, а не по цене бара-сигнала. Это свойство стратегии SMC (нужна структурная конфирмация), а не баг. Сканирование «самого свежего сигнала» делает советник нечувствительным к точной величине задержки.

## Риск-менеджмент советника (отдельные параметры с префиксом «СОВЕТНИК»)

| Блок | Параметры | Описание |
|---|---|---|
| **Источник сигналов** | `InpIndicatorName`, `InpSignalScanBars`, `InpDebugLog` | Имя индикатора для `iCustom`, глубина сканирования свежего сигнала, отладочный лог. |

## Бэктест

1. Тестер стратегий (`Ctrl+R`) → `SmartMoneyVolumeEA`, символ и ТФ. Индикатор подгрузится через `iCustom` автоматически.
2. Режим «Каждый тик на реальных тиках» рекомендуется (особенно для золота).
3. При первом запуске EA выполняет **прайминг**: уже существующий на графике сигнал не торгуется — советник реагирует только на сигналы, появившиеся **после** старта.

## Настройка стратегии под себя (LIVE) и «не открывает сделки»

Так как параметры индикатора нельзя передать через `iCustom` (лимит 63), советник умеет **брать сигналы с индикатора, уже добавленного на график** — с вашими настройками:

1. Добавьте на график индикатор `SmartMoneyVolume`, настройте его как нужно.
2. Поверх добавьте советник `SmartMoneyVolumeEA` (по умолчанию `InpUseChartIndicator=true`).
3. Советник найдёт индикатор по короткому имени `InpIndicatorShortName` (по умолчанию `SmartMoney+Volume MTF`) и будет торговать **ровно его** стрелки. Если индикатора на графике нет — фолбэк на `iCustom` с дефолтами (а в тестере — всегда `iCustom`-дефолты).

> Порядок важен: сначала индикатор, потом советник. Если добавили советник раньше — уберите и добавьте заново.

**Если сделок нет — диагностика.** При `InpDebugLog=true` (включён по умолчанию) советник в журнал («Эксперты»/«Журнал») печатает:
- сколько entry-сигналов индикатор дал в истории (`ДИАГНОСТИКА: ... BUY=.. SELL=..`). Если **0** — индикатор с текущими настройками не даёт входов на этом символе/ТФ → ослабьте пресет (включите `InpEntryUseScore` и понизьте `InpEntryMinScore`, либо отключите часть `Need`-условий);
- каждый найденный новый сигнал и **причину пропуска** (сессия/спред/лимиты/уже есть позиция);
- факт входа и ошибки ордера.

Частые причины «нет сделок»:
- **Дефолтный пресет селективен** (тренд + активный OB + объёмный бар одновременно) — сигналы редкие. Ослабьте пресет (см. выше) либо торгуйте свои настройки через индикатор на графике.
- **Прайминг** пропускает уже существующий сигнал. Чтобы проверить вход «здесь и сейчас», включите `InpTradeOnAttach=true` — советник возьмёт ближайший уже сформированный сигнал.
- Включён фильтр сессии/спреда или достигнут лимит позиций/сделок — смотрите причину в журнале.

> ⚠️ **Дисклеймер.** Из-за задержки подтверждения (`InpSwingLength` баров) вход происходит позже цены бара-сигнала — это влияет на результат и обязательно должно быть оценено в тестере. Перед реальной торговлей прогоните советник в Strategy Tester и на демо. Торговля сопряжена с риском потери капитала.
