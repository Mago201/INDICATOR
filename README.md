# SmartMoneyVolume — индикатор для MetaTrader 5

Индикатор объединяет концепцию **Smart Money Concepts (SMC)** и **анализ объёмов** в одном инструменте на главном графике MT5.

## Что показывает

| Элемент | Описание |
|---|---|
| **HH / HL / LH / LL** | Метки структурных свингов (Higher High, Higher Low, Lower High, Lower Low) |
| **BOS** (Break of Structure) | Сплошная линия пробоя предыдущего свинга в направлении тренда |
| **CHoCH** (Change of Character) | Пунктирная линия — смена характера рынка / разворот |
| **Order Blocks** | Прямоугольники зон последнего противоположного бара перед импульсом |
| **Fair Value Gaps (FVG)** | Прямоугольники имбалансов / 3-свечных гэпов |
| **Liquidity Sweeps** | Стрелки в местах снятия ликвидности (пробой + закрытие обратно) |
| **High-Volume bars** | Стрелки над/под барами, объём которых > среднего × множитель |
| **Volume label** | Опциональная подпись значения объёма (K/M) над баром |

## Установка

1. Откройте MetaTrader 5 → меню **Файл → Открыть каталог данных**.
2. Перейдите в папку `MQL5/Indicators/`.
3. Скопируйте файл [`Indicators/SmartMoneyVolume.mq5`](Indicators/SmartMoneyVolume.mq5) в эту папку.
4. В MetaEditor (`F4`) откройте файл и нажмите **Compile** (`F7`) — должна появиться `SmartMoneyVolume.ex5` без ошибок.
5. В MT5 в окне «Навигатор» обновите список индикаторов (правый клик → *Обновить*) и перетащите **SmartMoneyVolume** на график.

## Параметры

### Структура (Swing / BOS / CHoCH)
- `InpSwingLength` — сколько баров слева/справа должны быть ниже/выше для подтверждения свинга. Чем больше — тем «крупнее» структура. По умолчанию 5.
- `InpShowSwings` — рисовать метки HH/HL/LH/LL.
- `InpShowBOS` — рисовать линии BOS.
- `InpShowCHOCH` — рисовать линии CHoCH.
- `InpBullColor` / `InpBearColor` — цвета бычьих и медвежьих структур.

### Order Blocks
- `InpShowOB` — включить ордер-блоки.
- `InpOBMaxCount` — сколько последних OB держать на графике с каждой стороны.
- `InpBullOBColor` / `InpBearOBColor` — цвета.
- `InpOBExtendBars` — насколько баров вправо тянуть прямоугольник.

### Fair Value Gaps
- `InpShowFVG` — включить FVG.
- `InpFVGMaxCount` — лимит активных FVG на сторону.
- `InpBullFVGColor` / `InpBearFVGColor` — цвета.
- `InpFVGExtendBars` — длина зоны вправо.

### Liquidity Sweeps
- `InpShowLiquidity` — включить отметки sweep.
- `InpLiquidityColor` — цвет стрелки.

### Объёмы
- `InpShowVolume` — подсвечивать объёмные бары.
- `InpVolumeType` — `VOLUME_TICK` (тиковый) или `VOLUME_REAL` (биржевой; для MOEX/CME/крипты с реальным объёмом).
- `InpVolumePeriod` — период скользящей средней объёма (по умолчанию 20).
- `InpVolumeMultiplier` — во сколько раз объём текущего бара должен превышать среднюю, чтобы считаться «громким». 1.8 = +80 %.
- `InpShowVolText` — печатать численное значение объёма у бара.
- `InpVolTextColor` — цвет текста.

### Прочее
- `InpObjPrefix` — префикс имён графических объектов (на случай конфликтов).
- `InpAlertOnBOS` — звуковой алерт при BOS/CHoCH (только для свежих сигналов).
- `InpAlertOnSweep` — звуковой алерт при liquidity sweep.

## Идеи для использования

- **Тренд по структуре + вход по OB:** ждите BOS, затем вход в ближайший непротестированный Order Block в направлении тренда.
- **Контртренд по CHoCH + sweep:** sweep ликвидности противоположной зоны + CHoCH = ранний сигнал разворота.
- **Подтверждение объёмом:** сигналы SMC, совпадающие с громкой свечой (стрелка volume), статистически надёжнее.
- **FVG как магнит:** цена часто возвращается заполнить FVG — используйте как цель / зону интереса.

## Примечания

- Все свинги подтверждаются только после `InpSwingLength` баров справа от точки. Это означает, что текущие незакрытые бары не могут породить свинг — это нормально и предотвращает «перерисовку».
- Стрелки громких объёмов отображаются и для текущего бара, поэтому могут «мерцать», пока бар не закрылся.
- На младших ТФ имеет смысл увеличить `InpSwingLength` (8–10), на старших — уменьшить (3–5).
